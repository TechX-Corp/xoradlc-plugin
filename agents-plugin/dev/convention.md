# Convention mặc định của Xora DLC

Sensor dùng file này khi repo không có `convention.md` (hoặc `docs/convention.md`) của riêng nó. Repo có file riêng thì chỉ dùng file của repo.

Bộ luật mặc định sẽ được bổ sung sau: hiện chưa có luật nào, nên sensor chạy nhưng không cảnh báo gì.

```json
{"rules": []}
```
